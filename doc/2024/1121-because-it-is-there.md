# 因为山在那里

玩游戏 Celeste 时知道了一句名言，“[因为山在那里](url=https://zh.wikipedia.org/zh-hans/%E4%B9%94%E6%B2%BB%C2%B7%E9%A9%AC%E6%B4%9B%E9%87%8C)”，做为通关这款游戏的感慨。

这当然是个很炫酷的回答，一百多年来无数登山者、各种极限运动玩家，在面对相同的问题时引用这同一句话。但通常这并不是一个认真、诚实的回答，只是因为这句话够炫酷。

曾经玩《魔兽世界》的时候，最吸引人的新闻不是推出了什么新内容，而是新推出的 BOSS 会被哪个工会最先杀掉，称之为 First Down（FD），中国的水木清华和星辰两个工会都曾经拿过世界级 FD，但因为版本、更新周期等原因，大部分是国外的工会。但毕竟，游戏中怪物的行为是程序固定的，所有的行为可以预料，哪怕对操作的要求很苛刻，这类被通称为 [PvE](https://en.wikipedia.org/wiki/Player_versus_environment)，相对的是 PvP，玩家之间直接对抗，所以有一种论调的是玩家的行为更难预测、更难，所以，“打（那么呆的）怪有什么意思？”直到有个经常拿 FD 的工会的人在接受采访时说了一句话点醒了我，“真奇怪，总有一些人认为 PvE 是玩家跟怪物之间的竞争”。其实这类似田径和体育竞赛的区别。

半年前曾看到一句话，很可惜忘了原文和出处，但我一直在品味、推敲这句话，大意是，人所有的行为的最终动力来源，都是为了保持优越感。这跟我之前信奉的[需求层次理论](https://zh.wikipedia.org/zh-hans/%E9%9C%80%E6%B1%82%E5%B1%82%E6%AC%A1%E7%90%86%E8%AE%BA)完全不是一个路数，但我想了很久，都不知道如何反驳。最终我打算接受这个观点。

所以“因为山在那里”的问题在哪里？它没有诚实地展现自己的优越感，而包装为了一系列的美德：勇气、坚毅、冒险精神，等等。但是所有行为应该有目的，尤其是要花如此巨大的代价，如果说有科学家为了扩展人类知识的边界而不得不去一趟，大部分人要的只是“我有你没有”的值得炫耀的经历。

那么拓展一下优越感理论，就是所有人在用尽可能小的付出得到尽可能大的优越感。

那么再看[一条](https://x.com/yihong0618/status/1648681667001987072)：

> 当你停止创造，你的才能就不再重要，你所拥有的只剩下你的品位。而品位会裹挟你，让你排斥他人，变得狭隘。所以，要创造。

当初看的时候总觉得哪里不太对，后来有了优越感理论就解释得通了：如果我最擅长的是做点什么东西，那么做东西无疑是世界上最了不起的事情。我真的不排斥任何踏实做出东西，哪怕没什么用，像我写过很多代码，大部分都没什么用。但这里的问题是，人类里只有一部分人具有创造才能（所有才能都是，因为才能的定义基于人类总体水平相对来说的，任何智力正常的人都比狗有更多的创造力，但是跟人比就很难排得上号了），接受这观点的同时就陷入了一种困境，跟中国人信福音派是一样：信福音派是说，如果你选择信仰上帝，认为天堂和地狱都真的存在，就意味着你的所有已经过世的祖先、你那没有皈依宗教的父母、亲朋好友、爱人、子女，都得下地狱。如果你选择“创造”是检验人生的唯一标准，同样你所爱的那些人里，一定有缺乏创造力的人，那他们难道都算白活了么？

人们认为用年收入多少钱来衡量人之间的差距是粗鄙的，但粗鄙的是如何衡量人类，而不是如何衡量，用创造力或者寿命或者任何单位去衡量，跟用钱衡量一样粗鄙。

我的世界观里，越来越支持的一个观点是，命运的大部分是已经注定的，可变的通常只有细节和一些本就不确定的运气，哪怕有人认为通过自己努力改变了命运，但肯不肯努力很大程度上也是天生的。所以别人没做到你的优势项目的成绩，不是别人缺了什么，而人和人就不应该通过简单的标准来衡量。

继续解构下去，我写这段文字只是为了表现自己的“独醒”，但又一次，这符合了优越感理论。我不否认我要依靠优越感来生存，但优越感只是手段之一，最终追求的东西是什么？我称之为幸福。每个人的幸福都是不一样的，平和接受各自的幸福，追求自己的。

------

可能还需要解释一下，一边说追求各自幸福，一边抨击别人说“因为山在那里”，这不自相矛盾么？不矛盾，如果你是一名真正的登山爱好者，会对此嗤之以鼻，我是说给那些嘴上说的是山，心里想的是“别人怎么会看”的人。
